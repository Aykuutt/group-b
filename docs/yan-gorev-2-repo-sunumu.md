# Yan Görev 2: Açık kaynak repo sunumu

## Seçtiğim repo

- Proje: [Platane/snk](https://github.com/Platane/snk)
- Konu: GitHub katkı takvimini yılan animasyonuna dönüştüren araç
- İncelediğim kaynak: Projenin GitHub README dosyası
- Sunum biçimi: Derste yaklaşık 2 dakikalık sözlü anlatım

## Kısa sunum notu

Ben Platane adlı geliştiricinin `snk` reposunu seçtim. Bu araç, bir GitHub kullanıcısının katkı takvimini alıp katkı karelerini yiyerek ilerleyen bir yılan animasyonuna dönüştürüyor. Çıktı SVG veya GIF biçiminde kullanılabiliyor.

Projede dikkatimi çeken özelliklerden biri GitHub Actions ile otomatik üretim yapılabilmesi. İş akışı ayarlandığında animasyon düzenli aralıklarla yeniden oluşturulabiliyor. README'de ayrıca açık ve koyu tema için farklı görsel kullanımı ve renk paletlerini özelleştirme örnekleri var.

Repo içinde GitHub Action'ın yanında animasyonu üreten paketler ve yalnızca SVG oluşturmaya yönelik bir seçenek de bulunuyor. README, kurulum ve kullanım örneklerini gösterdiği için projeyi denemeyi kolaylaştırıyor.

Bu projeyi seçtim çünkü kendi GitHub profilimde de yılan animasyonu kullanıyorum. Görselin arkasında nasıl bir proje olduğunu merak ettim. İncelememden çıkardığım ders, açık kaynak projelerde anlaşılır bir README ve çalışır örneklerin yeni kullanıcıların projeyi kullanmasına çok yardımcı olduğudur.

## Sorulursa

- **Ne işe yarıyor?** GitHub katkı takvimini yılan animasyonu olarak gösteriyor.
- **Çıktı biçimleri neler?** README'de SVG ve GIF seçenekleri anlatılıyor.
- **Nasıl otomatikleşiyor?** GitHub Actions ile belirli aralıklarla yeniden üretilebiliyor.
- **Neden bu repoyu seçtin?** Profilimde benzer görseli kullandığım için arkasındaki aracı merak ettim.
